# ①課題名
家族と分かち合うエンディングノート（リッチ版）

## ②課題内容（どんな作品か）
- 自分のエンディングノートを書いて、家族と分かち合うためのアプリです
- 項目を5つの分野に分けました。分野のボタンを押すと、その分野の項目が並びます
  - 大切にしたいこと：大切にしてきたこと／好きなこと・楽しみ／これからやりたいこと
  - 医療・介護：延命措置／病名や余命を知りたいか／介護を受けたい場所／最期を迎えたい場所／代わりに決めてほしい人
  - お金・財産：使っている銀行や保険の会社名／大切な書類の置き場所／遺言書
  - 葬儀・お墓：葬儀の形／知らせてほしい人／お墓や供養のこと
  - 大切な人へ：メッセージ
- すべての書く欄で、音声入力ができます。話すのが楽な方も、書きやすいようにしました
- ノートは Firebase（Realtime Database）に保存されるので、離れて暮らす家族も、同じノートを読むことができます
- 家族だけが知っている「合言葉」で部屋に入り、Google アカウントでログインしてから使います
- 書いたノートは、紙に印刷して手渡すこともできます
- 自社で開発しているイノチAI（人生の物語を聴き、ケアへとつなぐAI）に、いつか組みこむことを考えて作りました
- 基本の形は「kadai04_ending-note」で、このリッチ版はそれをコピーして、項目を増やしたものです

## ③アプリのデプロイURL

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 各自の Google アカウントでログインします
- PW: なし
- 合言葉は、家族で自由に決めます（例：rich）

## ⑤工夫した点・こだわった点
### 項目を分野ごとにまとめる（リッチ版で足したこと）
- 分野のボタンを押すと、その分野のかたまりだけが出て、ほかはかくれます。いま開いている分野のボタンには色がつきます
- ボタンに data-cat という名札をつけておき、押されたボタンの名札を読んで、出すかたまりを決めています
- 延命措置と「病名や余命を知りたいか」は、「希望する／希望しない／家族に任せる／まだ決められない」のラジオボタンで選び、その下に理由や気持ちをひとこと書けるようにしました。
- 読む場所には、書いた項目だけを分野ごとに並べ、空の項目は出さないようにしました
- 前の形で保存したノートを開いても止まらないように、分野の荷物がないときは空の荷物 {} として読むようにしました
- すべての問いに「考えるヒント」をつけました。押すとひらいて、書く前に自分の気持ちや理由を考えるための問いが出ます

### 話して書けるように（リッチ版で足したこと）
- すべての書く欄の下に「🎤 話して入れる」ボタンをつけました。Chrome の音声認識を使っています
- 話した言葉は、いま書いてある文の最後につけ足されるので、少しずつ話して書きためることができます
- 聞いているあいだは、ボタンの色と文字が「● 聞いています…」に変わります

### 安心して使えるように
- お金・財産の分野のいちばん上に、「口座番号・暗証番号・パスワードは書かないでください」と表示しました
- Google ログイン（Firebase Authentication）をつけ、ログインした人にだけ合言葉の入力欄が出ます
- 「書いた人」は、ログインしている Google アカウントの名前から取っています。ほかの人の名前を名乗って書くことはできません
- ログアウトしたときは、合言葉、書く欄、ラジオボタン、読む場所の中身を、すべて画面から消します
- データベースのルールを、「ログインした人だけ読み書きできる」（auth != null）にしました
- 表示には .text() を使い、書かれた文字がそのまま文字として出るようにしました
- Firebase のキーは config.js に分けて、.gitignore で GitHub に載せないようにしました
- 保存しないままページを閉じようとすると、「保存していない内容があります」と確かめるようにしました。

### 高齢の方にも使いやすいように
- 文字は UD フォント（BIZ UDPゴシック）にしました
- 字の大きさを「ふつう・大きめ・とても大きい」の3段階から選べるようにしました。いま選んでいる大きさのボタンには色がつきます。AI家庭教師に"px"と"rem"の仕組みを教わったうえで、手伝ってもらって実装しました
- 白地に青の落ち着いた色にして、書く欄にはからし色の縁をつけました
- 書けない欄と押せないボタンは灰色にしました
- 「ノートを消す」は白地に赤い縁にして、「保存する」と見分けがつくようにし、あいだも広げました。押したときには確認の小窓（confirm）も出ます

## ⑥難しかった点・次回トライしたいこと（又は機能）
### 難しかった点
- 項目が増えたので、保存（荷物につめる）、表示（読む場所に出す）、書く欄に戻す、の3か所に、同じ項目を書く必要がありました。1か所でも名前がちがうと、その項目だけ出なくなります
- ラジオボタンは、ふつうの入力欄とちがい、「選ばれている札」を探して値を取る書き方（:checked）が必要でした。何も選ばれていないときのために、空の文字を入れるようにしました

### 次回トライしたいこと
- 高齢の家族が Google アカウントを持っていなくても使えるように、ほかのログインの方法も考えたいです
- 分野ごとに、どこまで書けたかがわかる印をつける
- AIとの対話から物語を作り、本人の価値観を推測・確認したうえでエンディングノートの下書きを作れるようにする
